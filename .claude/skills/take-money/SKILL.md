# take-money — оплата и упаковка

Цикл 4, 65 минут. Здесь залипают почти все — это ожидаемо и это самый ценный сигнал дня. Записывай затыки в `STUCK.md` подробнее обычного.

L3 закрыт, когда есть экран оплаты или заявки и **кнопка реально что-то делает**: списывает тестовые деньги или доставляет заявку туда, где её видно.

## Сначала выбери, что продаёшь

Одна строка в `SPEC.md`, до всякого кода:

> **[кто именно]** платит **[сколько]** за **[что получает]**.

Если на месте суммы «потом придумаем» — Цикл 4 встанет. Поставь любую конкретную цифру: 490 ₽, 1 900 ₽, неважно. Цифру всегда можно поменять, а её отсутствие блокирует всё остальное.

## Вариант А — форма заявки (15 минут)

Быстрее и честнее для большинства продуктов за день. Заявка ловит намерение, а на реальную оплату всё равно нужны юрлицо и оферта.

Экран: цена, что входит, поле email или телеграм, кнопка «Оставить заявку». Заявка уходит в Telegram — через Worker из `starters/tg-bot-worker` (там же лежит токен, в браузер он не попадает).

Заявка обязана быть видимой: если она упала в консоль или в `localStorage` — это не L3. Проверь, что сообщение реально пришло в чат.

## Вариант Б — CloudPayments, тестовый режим

Тестовый `publicId` выдан на созвоне 18.08. Боевой не бери, даже если знаешь его наизусть, и не клади в репозиторий — он публичный.

```html
<script src="https://widget.cloudpayments.ru/bundles/cloudpayments.js"></script>
```

```js
// TEST publicId. В код не хардкодить боевой.
const PUBLIC_ID = window.CP_PUBLIC_ID;

function pay({ amount, description, email }) {
  new cp.CloudPayments().pay('charge', {
    publicId: PUBLIC_ID,
    description,                 // видно покупателю и в выписке
    amount,                      // число, не строка
    currency: 'RUB',
    accountId: email,            // обязателен, если когда-нибудь захочешь подписку
    email,
    skin: 'mini',
    data: { product: 'hackathon-demo' }   // долетит до вебхука
  }, {
    onSuccess: () => { location.href = './thanks.html'; },
    onFail: (reason) => {
      if (reason === 'User has cancelled') return;
      showError('Платёж не прошёл. Попробуйте другую карту.');
    }
  });
}
```

Проверь до старта дня (на созвоне 18.08, не утром 19-го):

- виджет открывается с твоего живого URL, а не только с localhost;
- тестовая карта проходит. Актуальный список карт — в ЛК CloudPayments, раздел тестового режима; не бери номера из головы;
- после успеха человек попадает на экран «спасибо», а не остаётся на пустой странице.

Чек по 54-ФЗ, подписки и `customerReceipt` сегодня не трогай. Это часы работы и юрлицо. Одноразовый платёж — достаточно.

## Вариант В — ЮKassa

Имеет смысл, если у тебя уже есть тестовый магазин. Создание платежа требует секретного ключа, а значит серверной части — Worker из `starters/tg-bot-worker`. В браузер секретный ключ не кладётся ни при каких условиях.

Если тестового магазина нет — не заводи его сегодня, бери вариант А.

## Упаковка — вторая половина цикла

Без неё ссылка выглядит как черновик, и на кросс-тесте это первое, что заметят.

**Название.** Короткое, произносимое вслух, говорит о пользе. Проверка: скажи его соседу и посмотри, переспросит ли он.

**Иконка и favicon.** Хватит эмодзи в SVG — 30 секунд и работает везде:

```html
<link rel="icon" href="data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 100 100'><text y='.9em' font-size='90'>💸</text></svg>">
```

**OG-превью.** Без него ссылка в чате выглядит мёртвой, а её будут кидать весь вечер. Полный набор тегов и типовые ошибки — скилл `fixing-metadata`.

```html
<meta property="og:title" content="Сколько вы переплачиваете по кредиту">
<meta property="og:description" content="Одна цифра за 30 секунд. Без регистрации.">
<meta property="og:image" content="https://<твой-url>/og.png">
<meta property="og:url" content="https://<твой-url>/">
<meta name="twitter:card" content="summary_large_image">
```

`og.png` — 1200×630. Скриншот главного экрана подойдёт. Путь в `og:image` должен быть абсолютный: относительный не подхватится ни Telegram, ни WhatsApp.

**Тексты.** Заголовок говорит, что человек получит, а не как называется технология. Кнопка называется глаголом действия: «Посчитать», «Отправить заявку». Не «Далее» и не «Отправить».

**Проверка превью.** Кинь ссылку самому себе в Telegram. Telegram кэширует превью надолго — если картинка не та, поправь и проверь через `@WebpageBot`, иначе будешь смотреть на старое до вечера.

## Порядок, если времени мало

1. Цена и кнопка на экране — без этого L3 не считается.
2. Кнопка что-то делает: заявка доходит или тестовый платёж проходит.
3. OG-превью и favicon.
4. Название и тексты.
5. Всё остальное.
