# userflow — кликабельный HTML вместо ТЗ

Цикл 1. Продуктового кода ещё нет. Задача — за час получить один HTML-файл, который можно кликать, и короткую спеку.

Смысл: половина решений про продукт принимается, когда видишь экраны. Принять их сейчас дешевле, чем в 16:00.

Прежде чем писать разметку, возьми тему — скилл `design`, шаг 1. Две минуты: `data-theme` на `<html>` и строка со шрифтами. Прототип сразу выглядит как продукт, и вечером не придётся перекрашивать.

## Что считается сделанным

Один файл `flow.html`. Открывается двойным кликом. Показывает экраны главного пути, кнопки переключают их. Данные захардкожены. Никаких фреймворков, сборки и бэкенда.

## Порядок

### 1. Сформулируй одну строку

Прежде чем рисовать, запиши в `SPEC.md`:

> Человек, который **[кто]**, открывает продукт, чтобы **[что сделать]**, и уходит с **[что получил]**.

Строка описывает главный путь, а не весь продукт. Это не формальность: всё остальное выводится отсюда.

### 2. Перечисли экраны главного пути

Столько, сколько нужно сценарию. Типичный минимум: вход → ввод данных → результат → (что дальше), но продукт может быть и сложнее.

Единственная проверка: каждый экран лежит **на** главном пути, а не рядом с ним. Настройки, профиль, история, вторая роль — рядом. Их можно сделать позже, если останется время, но они не должны появиться раньше, чем главный путь заработает целиком.

### 3. Собери flow.html

Один файл. Экраны — `<section>`, переключение — добавить/убрать класс. Реальный текст, не «Lorem ipsum»: формулировки кнопок и заголовков — половина продукта, их надо увидеть.

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Флоу</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-neutral-50 p-4 font-sans">
  <div class="mx-auto max-w-sm space-y-4">

    <section data-screen="start" class="rounded-2xl bg-white p-6 shadow">
      <h1 class="text-xl font-semibold">Сколько вы переплачиваете</h1>
      <p class="mt-2 text-neutral-600">Одна цифра за 30 секунд.</p>
      <button data-go="input" class="mt-6 w-full rounded-xl bg-black py-3 text-white">Посчитать</button>
    </section>

    <section data-screen="input" hidden class="rounded-2xl bg-white p-6 shadow">
      <label class="block text-sm text-neutral-600">Платёж в месяц</label>
      <input class="mt-1 w-full rounded-xl border p-3" value="45 000">
      <button data-go="result" class="mt-6 w-full rounded-xl bg-black py-3 text-white">Показать результат</button>
    </section>

    <section data-screen="result" hidden class="rounded-2xl bg-white p-6 shadow">
      <p class="text-sm text-neutral-600">Переплата за срок кредита</p>
      <p class="mt-1 text-4xl font-semibold">1 240 000 ₽</p>
      <button data-go="start" class="mt-6 w-full rounded-xl border py-3">Ещё раз</button>
    </section>

  </div>
  <script>
    document.addEventListener('click', (e) => {
      const to = e.target.closest('[data-go]')?.dataset.go;
      if (!to) return;
      document.querySelectorAll('[data-screen]').forEach(s => s.hidden = s.dataset.screen !== to);
    });
  </script>
</body>
</html>
```

Экономит время: Tailwind с CDN, `hidden` вместо CSS-классов видимости, делегирование клика одним обработчиком вместо слушателя на каждую кнопку.

### 4. Пройди сам и назови дырку

Прокликай флоу целиком. На каждом экране спроси: что человек здесь не поймёт без объяснений? Первый ответ запиши в `SPEC.md` — на чек-ине про него и спросят.

### 5. Допиши SPEC.md

Шаблон в `templates/SPEC.md`. Пять пунктов, десять минут, не больше.

## Чего не делать

- Не подключать React, Vue, Vite, сборку. Один HTML-файл, ноль команд в терминале.
- Не рисовать настройки, профиль, онбординг и пустые состояния **в Цикле 1**. Сначала главный путь целиком, остальное — если останется время.
- Не писать бэкенд «раз уж всё равно проектирую».
- Не полировать вёрстку. Флоу нужен, чтобы принять решение, а не чтобы понравиться.

## Дальше

Флоу — не выкидышь. Из него получается настоящий продукт: те же секции, тот же HTML, вместо захардкоженных цифр — реальный расчёт. Начинай Цикл 2 с копирования `flow.html` в `index.html`, а не с чистого листа.
